# Bundled license texts

These complete texts come from the
[SPDX License List data](https://github.com/spdx/license-list-data/tree/main/text):
MIT, Apache-2.0, BSD-3-Clause, GPL-3.0-only, MPL-2.0, and Unlicense.

Only MIT and BSD-3-Clause's variable copyright fields have been replaced with
`__year__` and `__copyright_holder__` tokens. Other texts, including examples in
their appendices, are preserved. No network access is needed to select a license.

The repository's own license is separate from the license selected for a generated
project.
